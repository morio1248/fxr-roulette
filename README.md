# F×R 景品ルーレット

BNI 東京MSリージョン F×Rチャプターの定例会の最後に使う、景品抽選のルーレットです。

- 公開先：https://morio1248.github.io/fxr-roulette/
- 点数（当たりやすさ）：その週のネットワーキングリーダー表彰 1位5点・2位4点・3位3点、ほかのメンバーは1点
- 対象外：代理を出したメンバー・欠席者・メインプレゼンの人（景品を渡す人）
- 景品の写真・景品名、参加設定、当選履歴は、開いたブラウザごとに保存されます

毎週土曜の朝、その週の定例会スライドの内容で `index.html` の名簿・点数・メインプレゼンを自動で更新します。
